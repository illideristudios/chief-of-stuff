`toon_format` is vendored from the [TOON Python implementation](https://github.com/toon-format/toon-python), release `0.9.0-beta.1` (`9f8d6f9ff3c519a018039146c9e99709143a2988`), under its MIT license in `toon_format/LICENSE`.

Only the codec modules are included. The standalone coordinator install copies these files with the pinned scripts so mailbox commands do not need a network install or a Python package on each host. `inbox.py` handles the current specification's root empty-array spelling (`[]`); the upstream beta encoder otherwise emits legacy empty-array headers that remain accepted by TOON decoders.

`markdown_it` is vendored from [markdown-it-py](https://github.com/executablebooks/markdown-it-py), release `4.2.0`, with its only required runtime dependency, [mdurl](https://github.com/executablebooks/mdurl), release `0.1.2`. Their MIT licenses are in `markdown_it/LICENSE` and `mdurl/LICENSE`; the parser's upstream JavaScript license is preserved in `markdown_it/LICENSE.markdown-it` too.

The sources come from the PyPI wheels `markdown_it_py-4.2.0-py3-none-any.whl` (SHA-256 `9f7ebbcd14fe59494226453aed97c1070d83f8d24b6fc3a3bcf9a38092641c4a`) and `mdurl-0.1.2-py3-none-any.whl` (SHA-256 `84008a41e51615a49fc9966191ff91509e3c40b939176e643fd50a5c2196b8f8`). Only library files are included (no CLI or distribution metadata). Absolute imports of these packages are changed to relative imports so both script and package imports stay within `_vendor`. No optional parser packages are included or needed.

`page_common.py` configures `MarkdownIt('commonmark').enable('table')`, disables raw HTML, and adds the pages' existing forge-reference chips and bare HTTP(S) links after parsing. These files travel with the pinned scripts, just like the codec; rendering needs no package install or network access.
